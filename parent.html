قنوات الفرجة

منطقة الأهل

أدخل كلمة السر (مفتاح GitHub) مرة وحدة، وبتنحفظ على هالموبايل بس.

من وين بجيب كلمة السر؟
  1. افتح صفحة إنشاء Token على GitHub.
  2. Token name: اكتب farja. و Expiration: اختار No expiration أو أطول مدة.
  3. Repository access: اختار Only select repositories ثم farja.
  4. Permissions → Repository permissions → Contents: اختار Read and write.
  5. اضغط Generate token وانسخه والصقه هون.

إضافة قناة

اكتب اسم القناة، أو الصق رابطها (من تطبيق يوتيوب: مشاركة ← نسخ الرابط).
